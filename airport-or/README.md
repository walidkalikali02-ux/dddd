# بحوث العمليات في المطار — Airport Operations Research

نموذجان جاهزان للتشغيل لمسألتين كلاسيكيتين في تشغيل المطارات.

## التشغيل

```bash
pip install -r requirements.txt
python gate_assignment.py          # توزيع الرحلات على البوابات
python checkin_counters.py         # عدد كاونترات تسجيل الوصول
```

البيانات موجودة في مجلد `data/` بصيغة CSV، ويمكن تعديلها مباشرة.

## 1. توزيع البوابات (Gate Assignment) — برمجة خطية صحيحة (MILP)

**متغير القرار:** `x[f,g] = 1` إذا خُصِّصت الرحلة `f` للبوابة `g` (أو للموقف البعيد APRON).

**دالة الهدف:** تقليل إجمالي مسافة مشي الركاب:

```
min  Σ_f Σ_g  passengers_f × distance_g × x[f,g]
```

وللموقف البعيد "مسافة" عقابية كبيرة، لأن الركاب ينتقلون إليه بالحافلة.

**القيود:**
1. كل رحلة تُخصَّص لبوابة واحدة فقط: `Σ_g x[f,g] = 1`.
2. حجم الطائرة يجب أن يناسب البوابة (S < M < L).
3. لا يجوز وجود رحلتين في البوابة نفسها في الوقت نفسه، مع فاصل زمني (buffer) بينهما.

**خيارات:**
```bash
python gate_assignment.py --buffer 20 --apron-penalty 1500
```

**ملفات البيانات:**
- `data/flights.csv`: الرحلة، وقت الوصول، وقت المغادرة، حجم الطائرة، عدد الركاب.
- `data/gates.csv`: البوابة، أكبر حجم طائرة تستقبله، مسافة المشي بالمتر.

## 2. كاونترات تسجيل الوصول (Check-in) — نظرية الطوابير M/M/c

لكل ساعة، يُحسب **أقل عدد من الكاونترات** يجعل متوسط الانتظار في الطابور ≤ الهدف المحدد.

- `λ` = عدد الركاب الواصلين في الساعة
- `μ = 60 / مدة الخدمة` = عدد الركاب الذين يخدمهم كاونتر واحد في الساعة
- `ρ = λ / (c·μ)` = نسبة الإشغال، ويجب أن تكون أقل من 1
- صيغة **Erlang C**: احتمال أن ينتظر الراكب، ومنها `Wq = C(c,a) / (cμ − λ)`

**خيارات:**
```bash
python checkin_counters.py --service-min 3 --target-wait 5
```

**ملف البيانات:** `data/checkin_demand.csv` (الساعة، عدد الركاب في الساعة).
