# Tavola OS — Restaurant ERP (working name)

AI-first, cloud-native ERP for restaurants, from a single café to global chains.

## Documents

- [Product Requirements Document (PRD)](docs/PRD-Restaurant-ERP.md): vision, market positioning, personas, 21 functional modules with prioritized requirements (P0/P1/P2), non-functional requirements, architecture, data model, workflows, KPIs, roadmap, pricing, go-to-market, risks, and acceptance criteria.
- [WhatsApp Sales Agent](whatsapp-sales-agent/README.md): an AI agent (Claude) that reaches out to leads from your normal WhatsApp number via WhatsApp Web, replies, follows up, and is managed from a local web dashboard.
